# ig-cards — 인스타그램 예약 발행용 임시 저장소

(주)블루아이즈 인스타그램(@blueyes_3d) 자동 발행에 쓰는 저장소입니다.

- `queue/` — 발행을 기다리는 게시물(사진 + 캡션). **발행되면 사진과 함께 지워집니다.**
- `published/` — 발행 기록(주소·시각). 사진은 남기지 않습니다.
- `.github/workflows/publish.yml` — 15분마다 예약 시각이 된 게시물을 발행합니다.
- 발행 후에는 기록 없는 새 커밋으로 덮어써 저장소 용량이 쌓이지 않게 합니다.

사진은 인스타가 가져갈 수 있도록 **발행 전까지만** 공개됩니다.
